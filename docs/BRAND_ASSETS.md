# Folioyard brand assets

## Logo lockup

- `public/folioyard-logo.png` is the original selected raster reference. It remains preserved in the repository.
- `public/folioyard-logo-v2.png` is a transparent, dot-removed review derivative made from the selected reference. It is the current local lockup in the header, footer, and static homepage fallback.
- The derivative removes the detached coral dot below the F and the terminal coral dot after “folioyard.” The folded-page mark, wordmark, and existing palette remain the design reference. The generated raster may contain edge changes, so it is not an editable vector master.
- `public/folioyard-symbol.svg` is the favicon asset. It retains the F and sage folded-page detail without detached dots.

The V2 lockup is a review candidate on the current development branch, not a separate approved master. Keep the original reference unchanged until the revised asset is accepted and a vector master is available.
